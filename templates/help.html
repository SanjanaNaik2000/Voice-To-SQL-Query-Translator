How to give commands

Type a normal English sentence in the prompt box. Use your table and column names, and the app writes the SQL, checks it, and runs it. Examples below use the demo tables; replace the names with yours.

Show data

You typeIt becomes
{{ ex('show all employees', 'SELECT * FROM "employees";') }} {{ ex('show name and salary of employees', 'SELECT "name", "salary" FROM "employees";') }} {{ ex('unique departments', 'SELECT DISTINCT "department" FROM "employees";') }}

Filters (conditions)

You typeIt becomes
{{ ex('employees older than 30', 'SELECT * FROM "employees" WHERE "age" > 30;') }} {{ ex('employees in london', "SELECT * FROM \"employees\" WHERE \"city\" = 'London';") }} {{ ex('employees between 30 and 40 years old', 'SELECT * FROM "employees" WHERE "age" BETWEEN 30 AND 40;') }} {{ ex('employees not in london', "… WHERE \"city\" != 'London';") }} {{ ex('employees in london or paris', "… WHERE \"city\" IN ('London', 'Paris');") }} {{ ex('employees with salary at least 90000', '… WHERE "salary" >= 90000;') }} {{ ex('employees whose name starts with A', "… WHERE \"name\" LIKE 'A%';") }}

Words for comparing: older / more than / above / over (>), younger / less than / below / under (<), at least (>=), at most (<=), between … and …, not. Text with spaces goes in quotes: city is 'New York'.

Count, totals and groups

You typeIt becomes
{{ ex('how many employees in engineering', "SELECT COUNT(*) FROM \"employees\" WHERE \"department\" = 'Engineering';") }} {{ ex('average salary per department', 'SELECT "department", AVG("salary") FROM "employees" GROUP BY "department";') }} {{ ex('maximum salary per department', 'SELECT "department", MAX("salary") … GROUP BY "department";') }} {{ ex('count employees per department having more than 3', '… GROUP BY "department" HAVING COUNT(*) > 3;') }}

Words for totals: count / how many, sum / total, average, maximum, minimum. Use per or by before the column to group.

Sort and top N

You typeIt becomes
{{ ex('top 3 highest paid employees', 'SELECT * FROM "employees" ORDER BY "salary" DESC LIMIT 3;') }} {{ ex('show 3 cheapest products', '… FROM "products" ORDER BY "price" ASC LIMIT 3;') }} {{ ex('employees sorted by age descending', '… ORDER BY "age" DESC;') }} {{ ex('first 5 employees', '… FROM "employees" LIMIT 5;') }}

Several tables (joins)

You typeIt becomes
{{ ex('show orders and products', 'SELECT * FROM "orders" INNER JOIN "products" ON … ;') }}

Name both tables. The join uses foreign keys or matching column names; check the SQL card to be sure the link is the one you meant.

Insert a row

Pattern: insert into <table> <column> <value> <column> <value> … — give each column name followed by its value. Columns you leave out stay empty.

You typeIt becomes
{{ ex('insert into employees name Rex age 30 city Paris', "INSERT INTO \"employees\" (\"name\", \"age\", \"city\") VALUES ('Rex', 30, 'Paris');") }} {{ ex('add employee name Zoe salary 70000 age 28', "INSERT INTO \"employees\" (\"name\", \"salary\", \"age\") VALUES ('Zoe', 70000, 28);") }}

Change rows

You typeIt becomes
{{ ex('update employees set salary = 75000 where name is Bob', "UPDATE \"employees\" SET \"salary\" = 75000 WHERE \"name\" = 'Bob';") }} {{ ex('increase salary by 5000 for employees in sales', "UPDATE \"employees\" SET \"salary\" = \"salary\" + 5000 WHERE \"department\" = 'Sales';") }}

Without a condition, an update changes every row. Always say which rows (where … or for …).

Delete rows

You typeIt becomes
{{ ex('delete employees older than 50', 'DELETE FROM "employees" WHERE "age" > 50;') }}

A delete without a condition is blocked, so you can't wipe a table by accident. Deleted rows can't be undone; back up the .db file first if the data matters.

Create, change and drop tables

You typeIt becomes
{{ ex('create table pets with columns name text, age integer, weight real', 'CREATE TABLE "pets" ("name" TEXT, "age" INTEGER, "weight" REAL);') }} {{ ex('alter table pets add column owner text', 'ALTER TABLE "pets" ADD COLUMN "owner" TEXT;') }} {{ ex('alter table pets rename column owner to keeper', 'ALTER TABLE "pets" RENAME COLUMN "owner" TO "keeper";') }} {{ ex('rename table pets to animals', 'ALTER TABLE "pets" RENAME TO "animals";') }} {{ ex('drop table animals', 'DROP TABLE "animals"; (asks you to confirm)') }}

Data types: write the type after the column name (text, integer, real). If you leave it out, the app guesses from the name (age → integer, price → real) and otherwise uses TEXT. A TEXT column sorts numbers wrongly (9 after 10), so name numeric columns' types.

Dropping a table or column asks you to type the name to confirm, and cannot be undone.

You typeIt shows

Tips and limits

  • Check the Generated SQL card and the Insights tab to see why each part was chosen.
  • If it says it can't tell which column you mean, name the column in your sentence.
  • One request per sentence. Not supported yet: subqueries, comparing two columns, date phrases like "last month".
  • The SQL tab accepts SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER and DROP only (for the structure of a table use describe above).
  • Voice: press the microphone button and speak the same sentences within 5 seconds (offline Whisper; the first use downloads the model once). Numbers can be spoken ("ninety thousand"). If it mis-hears you, the error shows what it heard.
  • History and favorites are saved in history.json, so they are still there next time. Use the ✕ on a card to delete one entry, or Clear history / Clear favorites to remove them all.
